# 休息提醒助手

🦞 每45分钟提醒你站起来休息的桌面工具

## 功能特点

- ⏰ **智能计时**：45分钟工作 + 5分钟休息
- 🔔 **系统通知**：原生桌面通知提醒
- 🔒 **可选锁屏**：休息时自动锁定屏幕
- 🎨 **精美界面**：现代化渐变UI设计
- 📊 **使用统计**：记录每日工作/休息数据

## 使用方法

1. 下载对应系统的版本
2. Windows：双击运行，无需安装
3. Linux：添加执行权限后运行

## 配置

首次运行会自动创建 `config.json`：

```json
{
  "workDuration": 45,    // 工作时长（分钟）
  "restDuration": 5,     // 休息时长（分钟）
  "enableLock": false,   // 休息时锁屏
  "sound": true          // 提示音
}
```
